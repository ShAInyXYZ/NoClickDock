# NCD 2 — plan and loop

Contracts: [ARCHITECTURE.md](ARCHITECTURE.md), [../../DESIGN.md](../../DESIGN.md),
per-widget parity specs in [specs/](specs/). Branch: `rewrite/tauri-go-svelte`.

## Agents

| agent | role | writes |
|---|---|---|
| **research** (supervisor 1) | Behavioural parity and platform truth. Writes the specs from the Python source, proves Tauri/Windows questions with experiments, reviews the Go core and Rust shell for correctness, parity, Windows behaviour, security. | `specs/`, `research/`, `reviews/M*-research-r*.md` |
| **design** (supervisor 2) | Visual and interaction quality against DESIGN.md. Runs the UI in a browser against `ncd-core --mock`, screenshots every surface and state with Playwright, and reviews the real Tauri windows on X11. | `reviews/M*-design-r*.md`, `reviews/shots/` |
| **executor** | Builds. The only agent that edits code. | everything else |

Supervisors never edit code; they write findings with file:line references
and a verdict. The orchestrator (main session) relays findings, arbitrates
disagreements, and advances milestones.

## Loop, per milestone

1. Executor implements the milestone, self-verifies (build, `go test ./...`,
   `go vet`, `pnpm check`, a browser screenshot of what changed), commits,
   and writes `reviews/M<n>-exec.md`: what was built, how it was verified,
   what is known to be missing.
2. Both supervisors review in parallel and each writes
   `reviews/M<n>-<role>-r<k>.md` ending in **VERDICT: PASS** or
   **VERDICT: FAIL** with a numbered must-fix list (and a separate,
   optional should-fix list).
3. Any FAIL → the executor fixes the must-fix items, commits, and the failing
   supervisor re-reviews (round k+1). Both PASS → next milestone.
4. After round 4 the orchestrator arbitrates what is left.
