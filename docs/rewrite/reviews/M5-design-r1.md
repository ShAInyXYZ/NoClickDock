# M5 — design review, round 1 (ComfyUI, Power, power report)

Reviewer: design supervisor, 2026-09-26. **Tree:** a clean `git archive` of
`7dd2612`. Browser `--mock`: the harness audit covers 36 surfaces with 0
findings and 0 console errors.

Edge cases were rendered by the real writer in a throwaway scratch test
(invented data). The report was generated by `writeReport` from the invented
25-day log in `testdata/pmlog`. Shots are in `shots/M5/`.

**What passes:**
- **ComfyUI:**
  - devices under one-row section headers;
  - VRAM and RAM meters with values;
  - one stats line per device;
  - busy is `generating · 42%` in `--info`, with the progress arc on the dial
    and the indeterminate arc in `dial/spin`;
  - offline is one sentence, with the endpoint in a chip.
- **Power:**
  - the thermal alert comes first;
  - one table with Draw, Storage, Displays and USB groups on one set of
    columns;
  - the donut is monochrome;
  - 24 clock-hour bars, where an unmeasured hour draws nothing;
  - utilisation meters: RAM and VRAM tone at 90/97, CPU never tones;
  - the tariff window reads `off-peak until Mon 06:00`;
  - temperature tones follow M5-b (core 71° untoned, VRAM 92° warn);
  - an unreadable RAPL counter gives `~52` plus a sentence saying why, and
    `CPU estimated` in the footer (`power-estimated@2x.png`).

## MUST-FIX

1. **The power report is not in the dock's identity, and it uses refused
   patterns.** The page opens from the menu and a user reads it
   (`shots/M5/report-top.png`).
   - Wrong identity:
     - it is the old palette (`#0e0d0b`, amber `#e8873a`);
     - its fonts are Inter and JetBrains Mono, which are not bundled, so it
       renders in DejaVu here;
     - GPU is green and CPU is blue.
   - Refused by DESIGN.md:
     - a row of KPI tiles;
     - every section boxed as a card;
     - an amber left border on the summary;
     - an eyebrow (`NOCLICKDOCK · POWER`) over the title;
     - green and blue category bars.
   - **Fix:**
     - Inline `tokens.css` and embed Manrope and IBM Plex Mono (woff2 as
       `data:`).
     - Use one-row section headers on `--bg`, with hairlines instead of
       cards.
     - Put the headline figures in a stats line or a table.
     - Keep charts monochrome (`--text`/`--muted`/`--dim` segments). Use
       `--accent` only for the one signal: the peak-tariff share and the
       hottest hours.
     - No left border and no eyebrow.

2. **A GPU whose core is critical is announced as its memory junction.**
   - One alert per GPU, and VRAM wins whenever it is ≥ 90 °C. With the core
     at 92 °C (crit) and VRAM at 92 °C (warn):
     - the header reads `GPU0 VRAM 92°C` in crit;
     - the alert reads "memory junction is at 92°C" in crit red;
     - meanwhile the VRAM cell is amber and the core cell red
       (`power-core-crit-named-vram.png`).
   - This breaks M5-b / A20 (cell, lamp, label and toast agree).
   - **Fix:** name the worse sensor: crit beats warn, and the core wins a
     tie. Or give each sensor its own alert.

Non-blocking items are in `FOLLOWUPS.md`.

VERDICT: FAIL
